# MetaRea World GUIDE

VRChatワールドへ配置するワールド紹介ボードです。

## 0.14.0の配置

- **Packages/net.metarea.worldguide/Core**：動作スクリプト、内部プレハブ、画像、フォント、マテリアル、設定用Editor。
- **Assets/MetaRea_World_GUIDE/MetaRea World GUIDE.prefab**：利用者が配置・設定するPrefab Variant。
- **Assets/MetaRea_World_GUIDE/UserContent**：独自素材・利用者用設定。配布更新の対象外です。
- **Assets/MetaRea_World_GUIDE/README.txt**：導入案内。

設置用プレハブをHierarchyへドラッグして配置します。位置・配色・お気に入りは従来の設定画面で変更できます。

## 更新と移行

0.12以前の管理対象ファイルをバックアップし、本体をGUIDを維持してPackagesへ移します。既存の設置用VariantとそのGUID・設定は上書きしません。独自ファイルは削除しません。配布本体へ直接加えた変更は更新対象となり、変更前をプロジェクト直下のMetaReaWorldGuideBackupsへ退避します。独自素材はUserContentへ置いてください。

配置中に失敗した場合はファイルを復元します。中断した移行は次の起動で復元してから再試行します。修復メニューは「MetaRea → パッケージ配置を再試行」です。

SDK依存条件はcom.vrchat.worlds >=3.10.5です。上限は設けませんが、将来SDKでの動作保証とは別です。

## 広告・画像表示

新しいサーバーパッチ045のguide-v4配信に対応します。旧guide-v3配信は維持されます。新配信が利用できない初期接続では旧配信へフォールバックします。同一インスタンス内では配信形式を混在させません。

初期シート2048×1920にカード6枠（512×288）、バナー3枠、日替わり3枠、各一覧8枠ずつ、初期広告の詳細プレビュー9枠を予約します。画像と掲載確認が揃ってからTOPを一括表示します。詳細を開くと軽量画像を即表示し、高画質版→QRの順で取得します。待機・取得・再試行の状態を小さく表示します。

サーバーパッチの適用前には新シート仕様を利用できません。アーカイブ側のパッチは別途適用が必要です。

## 配布物の作成（開発者向け）

編集元の本体はPackages/net.metarea.worldguide/Coreです。ci/build_vcc_payload.py --output <新しい出力フォルダ> で検査済みVCC用ZIPを生成します。Unityが旧Assetsと新Packagesの同一GUIDを同時インポートしないよう、配布ZIPは独立した更新処理と非インポートのPayload~を持ちます。更新処理が旧管理ファイルを退避してから、本体をPackages内のCoreへ展開します。利用時の本体配置はPackagesです。

検査対象はGUID重複、意図しない外部参照、Scene・SDKファイルの混入、バージョン整合性です。新規導入・既存設定保持・復元・Udonコンパイルも別途確認します。

VCC配布一覧: https://metarea-system.github.io/metarea-world-guide/index.json
0.13.0ではBOOTHショップURLボタンと、8種類のプリセットに連動するアイコン配色も利用できます。

## 0.13.1の変更

オンライン用ボードは、ワールドビルド時にサンプル画像・サンプル広告・編集用プレビューへの参照を外します。編集画面のプレビュー、実行時の状態画像とロゴ、オフライン用サンプルは維持します。

お気に入りはAssets/MetaRea_World_GUIDE/UserContent/Favoritesの保存データへ移行し、パッケージ更新で保持します。シーンを保存して関連付けを保持してください。ボードを再配置する場合は、設定画面の「保存データ」で既存の一覧を選びます。同じ保存データを選んだボードは一覧を共有し、複製ボタンで別の一覧にできます。保存データが見つからない場合は登録を空にしてアップロードせず、ビルドを停止します。


## 0.13.2の変更

TOPの広告画像を356×200.25に拡大しました。4枠表示は画像を356×138へ広げ、ワールド名と紹介文を各1行に整理し、作者名との余白を詰めました。長いタイトル・紹介文・広告タイトルは使用中のフォントの実際の表示幅で判定し、枠内に収まる位置へ「…」を付けます。詳細画面の本文は省略しません。

## 0.13.4の変更

広告なしの4枠表示の画像を356×180から356×230へ拡大しました。画像の縦横比を保持し、文字間隔10px・作者名の位置・カードサイズ・広告ありの表示は維持します。

## 0.14.0の変更

匿名統計をschema 2へ移行しました。board_readyは同一クライアント・共有管理単位の表示準備完了初回、portal_request_acceptedは操作側の受付、portal_owner_acceptedは所有者側の受付を表します。通常・広告・お気に入りのポータルに対応します。閲覧人数・ポータル表示成功・移動成功は測定しません。schema 1の通信結果イベントは送信しません。

設定の「統計の設置先コード」は英数字・_・-の1～64文字で、未設定はunknownです。「統計の環境」は本番(production)・テスト(test)・未分類(unknown)から選びます。同一シーンの全ボードで揃えてください。コードは秘密情報ではなく、公開可能な設置先分類です。ユーザーID・セッションID・ワールドIDを追加送信しません。1台でも既存の統計設定を無効にすると共有管理全体の送信を止めます。

Editor/ClientSimでは統計および広告クリックを送信しません。送信フラグはビルド用シーンコピーだけで有効になります。VRChat内のテスト用ビルドは環境をtestに設定してください。通常の配信JSON取得は引き続き発生します。

操作は60秒単位で統合せず、各受付を64件のFIFOキューへ保存します。送信は開始60～75秒後から最短10秒間隔、同一クライアントの共有管理単位で最大128件、待機期限300秒、再送なしです。読み込みを優先するため、短時間の滞在・通信不調・期限切れ・上限超過では未送信が発生します。Web側は受信件数として表示し、真の利用総数や成功率とは区別してください。広告詳細の既存30分重複抑制は別系統のままです。

受信契約: GET /api/udon/telemetry?schema=2&version=0.14.0&event=board_ready|portal_request_accepted|portal_owner_accepted&site=コード&environment=production|test|unknown&protocol=v2|v3|v4|unknown。protocolはイベント受付時に固定します。WEB側の更新パッチ047適用後からschema 2を受信できます。GUIDEをVCCで更新し、統計設定を反映してワールドを再公開してください。047の本番適用はこのパッケージ公開では実行しません。再送識別子を持たないためサーバーは個人単位の重複排除を推測せず、統計URLをキャッシュしないでください。
