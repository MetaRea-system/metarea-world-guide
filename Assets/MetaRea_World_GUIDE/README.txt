MetaRea World GUIDE 0.17.4

はじめて導入する方へ
1. VCCでWorld用プロジェクトを作成します。動作確認環境はUnity 2022.3.22f1 / VRChat SDK Worlds 3.10.6です。保存先はC:/VRCProjects/MyWorldのように親フォルダーも含め半角英数字にすると、パスに起因するUnityの問題を避けやすくなります。
2. Unityを閉じ、VCCでMetaRea World GUIDEを追加してから、Unityを開きます。インポートとコンパイルが終わるまで待ってください。
3. 環境診断が表示されたら案内を確認します。必須レイヤー・衝突設定が未設定の場合は「バックアップしてSDK標準設定を適用」を押します。独自の衝突設定があるワールドでは変更内容も確認してください。診断はMetaReaメニューからいつでも開けます。
4. 「MetaRea → 導入用プレハブを表示」で表示されるプレハブをHierarchyへドラッグし、位置と向きを調整してシーンを保存します。
5. VRChat SDKのControl PanelでBuilderを開き、指摘されたワールド側の問題を解消します。Build & Testで動作を確認後、ご自身のアカウントからBuild & Publishを行ってください。

更新するとき
・プロジェクトをバックアップし、シーンを保存してUnityを閉じ、VCCで更新します。
・設置済みボードを削除・再配置する必要はありません。Assets側の配置・配色・お気に入りを引き継ぎます。
・インポート完了後に診断とSDKのBuilderを確認し、ワールドを再ビルド・再公開すると更新内容がVRChatへ反映されます。
・Packages内の本体は直接編集せず、独自素材やお気に入りはAssets側で管理してください。

お気に入りはフォルダ形式（初期値）／ワールド一覧を選択できます。
フォルダ説明文は「お気に入りワールド設定」で入力し、件数の代わりに表示します。
ワールド一覧ではフォルダを残したまま全登録をまとめ、同じワールドは最初の1件だけ表示します。
新規配置の表示形式は4枠です。
TOPのworld型広告は直接ポータルを要求します。広告別ポータル内訳にはArchiveパッチ051が必要です。

配置：Assets/MetaRea_World_GUIDE/MetaRea World GUIDE.prefab をHierarchyへドラッグしてください。
位置・お気に入り・配色は設置したオブジェクトの設定から変更します。

本体：Packages/net.metarea.worldguide/Core
利用者用：Assets/MetaRea_World_GUIDE
独自素材：Assets/MetaRea_World_GUIDE/UserContent（更新対象外）

既存の設置用プレハブとGUID・設定は更新時に保持します。
本体はVCCパッケージに直接収録され、Unity起動後の展開待ちがありません。
配布本体への直接編集はVCC更新で置き換わります。独自設定・素材はAssets側のプレハブ・UserContentで管理してください。
Assetsに本体がある旧構成は、先に0.17.0のバックアップ付き移行を完了してから更新してください。
配置失敗時は「MetaRea → パッケージ配置を再試行」を利用してください。

広告詳細はプレビューを即表示し、高画質版、QRの順で取得します。
高画質版DL待機中／DL中／再取得予定は、詳細画像の右下に表示されます。
新広告仕様にはArchive側パッチ045以降のguide-v4配信が必要です。
配信が未提供の初期接続では旧配信へ戻ります。旧配信では新広告仕様は使われません。
新配信適用後は、新しいインスタンスで確認してください。

必要なSDK：com.vrchat.worlds 3.10.5以上。将来のSDKでの動作は個別確認が必要です。

お気に入りの保存（更新保護）
・シーンの「お気に入りワールド設定」で登録すると、Assets/MetaRea_World_GUIDE/UserContent/Favorites の専用データに保存します。
・既存の登録は初回に自動で引き継ぎます。保存データとの関連付けはシーンを保存して保持してください。
・パッケージ更新ではUserContentを削除・上書きしません。ボードを再配置した場合は「保存データ」に既存の一覧を選んでください。
・同じ保存データを選んだボードは一覧を共有します。別の一覧にする場合は「保存データを複製して別の一覧にする」を使います。
・バックアップ／他プロジェクトへの移行ではUserContentフォルダと.metaも一緒に保存してください。
・保存データが見つからない場合は、登録を空にしてアップロードせず、ビルドを止めます。

ワールドビルド時の画像除外
・オンライン用ボードは、サンプルワールド画像・サンプル広告・編集用プレビューの参照をビルド用シーンから外します。
・ロゴ、X／BOOTH／アーカイブのアイコン、読込中・取得失敗・画像なしの表示は残します。
・編集画面のプレビューとオフライン用ボードのサンプル表示は維持します。
・画像を別のオブジェクトから独自に参照している場合、その参照によって画像がビルドに含まれることがあります。

統計schema 2はWEB側パッチ047適用後から受信できます。VCC更新後、統計の設置先コードと本番／テスト設定を確認し、ワールドを再公開してください。Editor／ClientSimからは統計を送りません。短時間の滞在や送信制限で未送信が生じるため、受信数は利用総数ではありません。

ビルド時の環境エラー（2026-11-06確認）
GUIDEのInspectorまたはMetaReaメニューの「ビルド環境を診断」で確認してください。
・「You must address Layers and Collision Matrix issues before you can build」: VRChat SDKの必須レイヤー／衝突設定が旧設定の可能性があります。SDK 3.10.6ではレイヤー3にItemが必要です。診断画面からSDK標準設定を適用できます。プロジェクト全体の物理設定に影響するため、適用確認と変更前バックアップを行います。既存の独自設定も確認してください。
・「ExecutionEngineException: String conversion error」: SDKのアセンブリ情報取得時にMono例外が出ることがあります。日本語などを含むプロジェクト保存先が原因の場合は、Unityを閉じ、元プロジェクトを残してC:/VRCProjects/WorldGuideなど親フォルダーまで半角英数字の場所へコピーし、VCCに追加して開いてください。Assets（お気に入り含む）・Packages・ProjectSettingsを保持します。GUIDEの再配置や再インストールでは解消しません。
この診断はシーン全体のビルド成功を保証しません。VRChat SDKのBuilderで最終確認してください。
