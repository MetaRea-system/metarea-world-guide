# MetaRea World GUIDE

VRChatワールドに設置するワールド紹介ボードです。通常版とお気に入り版、8種類の配色プリセットを収録しています。

## 導入

VCCでMetaReaのVPMリポジトリを追加し、このパッケージをワールドプロジェクトへ導入してください。Unity 2022.3.22f1 / VRChat Worlds SDK 3.10.5で確認しています。

`Packages/net.metarea.worldguide/Runtime` の `MetaRea World GUIDE` または `MetaRea World GUIDE Favorites` プレハブをシーンへ置きます。お気に入り版は子オブジェクトの「お気に入りワールド設定」で登録内容を編集します。設定後にシーンを保存し、Build & Testで確認してください。画像・情報の表示にはVRChatの Allow Untrusted URLs を有効にしてください。

## 複数ボード

同じシーンのボードは、自動作成される `MetaRea World GUIDE Shared Data` を通じて一覧と抽選結果を共有します。このオブジェクトは削除・非表示にしないでください。各ボードのタブ、ページ、詳細表示は独立しています。配信設定を変更した場合は、MetaReaメニューの「複数ボードの共通データ接続を更新」を実行してください。設定が異なるボードを混在させるとビルド時にエラーになります。

抽選画像のURLが期限切れになった後の途中参加者には一覧情報だけを表示し、次の再抽選で画像も更新します。

## スポンサー広告

World Archive管理画面の先頭で「ワールド広告」「画像広告」「画像＋ワールド広告（高級プラン）」のいずれかを選択します。TOPのスポンサー枠では、ワールド広告はクリックするとポータルを出し、画像広告は詳細画像を表示します。画像＋ワールド広告は詳細画像と「PORTAL この世界へ」ボタンを表示します。

画像広告と複合広告は下部バナーにも表示されます。下部バナーからは従来通り画像を開き、ポータルボタンはTOPから複合広告を開いた場合に表示します。掲載終了・停止、または配信状態を確認できない場合は広告を非表示にし、開いている広告詳細も閉じます。既存の通常バナーと旧ワールド広告データにも対応しています。

## 見た目とリンク

ルートのInspectorで配色プリセット、タイトルとリンクの色を設定できます。ミッドナイトではアーカイブの公式ロゴの元の色を使用します。右上のXとワールドアーカイブのロゴを押すと、それぞれのURLを表示します。

開発時の詳しい設定は `Runtime/README.txt` を参照してください。
