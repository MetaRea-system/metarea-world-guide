MetaRea World GUIDE v0.8.2

導入
VCCで作成したVRChat Worldsプロジェクトにインポートしてください。
確認環境：Unity 2022.3.22f1 / Worlds SDK 3.10.5。
Assets/MetaRea_World_GUIDE 内のPrefabをシーンへ配置します。
・MetaRea World GUIDE：通常版
・MetaRea World GUIDE Favorites：お気に入り対応版
既存の配置がある場合は、重複配置せず更新してください。

配色
ルートのInspector →「配色プリセット」→「配色」で選びます。
ミッドナイト／ウォルナット／アイボリー／ローズ／スカイ／セージ／ラベンダー／ストーン。
文字・本体の背景・カード・ボタン・枠線がまとめて変わります。
「色を個別に調整」を開くと自由に変更できます。既存の独自配色は「カスタム」と表示されます。
写真・広告・Xの画像はプリセットによる変更対象外です。
Play停止中に設定し、シーンを保存してください。

設置
位置と大きさはTransformで調整します。
TOPの2枠目、ポータル出現位置、共有待機時間はルートのInspectorで設定します。
ポータルの出現位置には十分な空間を確保してください。

お気に入り対応版
子オブジェクト「お気に入りワールド設定」を選びます。
「＋ ワールドを追加」でワールドURLまたはID、タイトル、作者名を入力します。
↑↓で順序を変更できます。1ページ8件、写真なしの一覧です。
行を押すと登録先の共有ポータルが出ます。配布時の一覧は空です。

確認
設定後にシーンを保存し、Build & Testで確認してください。
画像・情報の表示にはVRChatの「Allow Untrusted URLs」を有効にしてください。
配信に関する内部設定と開発用参照は通常のInspectorには表示しません。
この表示整理はソースコードの暗号化・コピー防止ではありません。

配布
MetaReaメニューの「配布パッケージを書き出す（MetaReaのみ）」を使用します。
SDK本体をこのパッケージに含める必要はありません。
この版はunitypackage形式です。VCCのリポジトリ配布には別途VPM化と公開設定が必要です。
