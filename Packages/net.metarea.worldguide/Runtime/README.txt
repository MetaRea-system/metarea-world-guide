MetaRea World GUIDE — 開発版

導入
VCCのMetaReaリポジトリからパッケージを追加します。
確認環境：Unity 2022.3.22f1 / Worlds SDK 3.10.5。
Packages/MetaRea World GUIDE/Runtime 内のPrefabをシーンへ配置します。
・MetaRea World GUIDE：通常版
・MetaRea World GUIDE Favorites：お気に入り対応版

複数設置
同じシーンへ複数のボードを置くと「MetaRea World GUIDE Shared Data」が自動作成されます。
データ管理オブジェクトは表示用ボードの外にあります。削除・非表示にしないでください。
初期一覧と再抽選は管理役の所有者が取得し、参加者へ同期します。
画像と広告の有効性確認は各参加者の端末で1組を取得し、その端末の全ボードで共有します。
設置台数による重複取得を抑えますが、参加人数分の画像取得は必要です。
おすすめ・ランダムの再抽選待機時間は全ボード・参加者で共通です。
各ボードのタブ・ページ・詳細画面は個別に操作できます。
更新時に読んでいる詳細は保持し、一覧へ戻ったときに新しい結果へ切り替えます。
非表示だったボードは再表示時に最新結果を受け取ります。
異なる配信設定を混ぜた場合はビルド時にエラーで知らせます。
接続が更新されない場合はMetaReaメニューの「複数ボードの共通データ接続を更新」を実行します。

途中参加と再抽選画像
途中参加者にも確定済みの一覧・抽選結果を同期します。
配信側の抽選画像には有効期限があります。期限後に初めて参加した端末では、
別の抽選の画像を誤表示しないため一覧情報だけを表示し、次の再抽選で写真も更新します。
すでに取得済みの端末ではキャッシュした画像を表示できます。
通信失敗時は前回の正常な結果を残します。

タイトルと配色
「MetaRea title」と「WORLD GUIDE title」は別々の画像オブジェクトです。
ルートInspectorの「タイトルの色」で、それぞれの色を変更できます。
「配色プリセット」で配色を選ぶと、タイトル色もその配色へ合わせます。
その後、タイトル色とXアイコン・ワールドアーカイブログの色を個別に変更できます。
ミッドナイトではワールドアーカイブのロゴに元の色を使用します。
画像の濃紺の色に影響されず着色できる専用UIマテリアルを使用しています。
ミッドナイト／ウォルナット／アイボリー／ローズ／スカイ／セージ／ラベンダー／ストーン。
「色を個別に調整」では本文・背景・カード・ボタン・枠線を変更できます。
Play停止中に設定し、シーンを保存してください。

公式リンク
右上のワールドアーカイブ公式ロゴで https://metarea.net/ を表示します。
隣のXアイコンで公式XのURLを表示します。外側または×ボタンで閉じます。
URLの表示機能であり、VRChatから外部ブラウザーを自動起動する機能ではありません。

設置・お気に入り
位置と大きさはTransformで調整します。
TOPの2枠目、ポータル位置、ポータル待機時間は各ルートInspectorで設定します。
お気に入り版の登録は子オブジェクト「お気に入りワールド設定」で行います。
登録内容・順序・配色はボードごとに保持します。1ページ8件、写真なしです。

確認・配布
画像・情報の表示にはVRChatの「Allow Untrusted URLs」を有効にしてください。
設定後にシーンを保存し、Build & Testで確認してください。
VPM配布対象はPackages/net.metarea.worldguideです。
公開時はpackage.jsonのバージョンを更新してGitHubのリリース手順を実行します。
SDKやUnity MCPなどの開発ツールをパッケージの依存関係へ追加する必要はありません。
